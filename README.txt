Bean's Quest 关卡设计器界面美化
========================================

把关卡设计器（课程列表 + 编辑器）里 imgui 风格的扁平控件，全部换成游戏自带的界面贴图。
基于提交：3c2cd2d feat. creative

文件
----
src/maker_ui.h          通用控件改用游戏贴图：设置菜单的绿色按钮（黑色粗体字，删除用红字）、
                        暂停菜单深色框、过关绿色面板与黑色分数框、黑色胶囊条与底板、圆形箭头、
                        图标按钮、四角聚焦框、菜单天空与云
src/maker_browser.h     课程列表重做：MAKER 标志标题、圆形返回与翻页按钮、按主题世界配色的卡片、
                        课程开头画面"照片"（真实砖块/物件/Bean）、关卡选择的奖励徽章与太阳星、
                        世界标志主题选择、绿色面板删除确认、音乐开关按钮
src/maker_editor.h      编辑器工具栏 / 物件栏 / 状态栏 / 属性面板 / 课程设置 / 全部物件 / 帮助 /
                        提示气泡改用游戏贴图；窗口过窄时自动缩小字号、收紧按钮、工具栏折成两行
src/maker.h             试玩提示条改用 HUD 底板
maker-ui-restyle.patch  以上四个文件相对 3c2cd2d 的完整补丁
preview/                本地软件渲染器跑真实绘制代码生成的预览图（不是游戏实机截图）

使用方法（二选一）
------------------
1. 把 src/ 下四个文件覆盖到项目的 src/ 目录
2. 在项目根目录执行：git apply maker-ui-restyle.patch

和原来行为不同的地方
--------------------
- 课程列表底部的 Back 按钮去掉，改为左上角圆形返回按钮（Esc 照常可用）
- 课程列表右下角新增音乐开关（与 M 键相同）
- 课程卡片缩略图由色块示意图改为开头画面照片，每帧读取一个课程，翻页后约 12 帧全部显示
- 编辑器工具栏高度 22 -> 24；窗口太窄时折成两行，不再丢弃 Save / 设置等按钮
- 物件栏放不下时隐藏世界筛选（"全部物件"窗口里仍可用）
- edDrawObject 新增可选参数 marks（课程照片里关闭编辑器专用标记）
